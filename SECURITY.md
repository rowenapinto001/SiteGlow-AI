# Security Policy

## Supported versions

The latest release is supported. SiteGlow AI is a browser extension, so the
version that matters is the one installed from the store.

## Reporting a vulnerability

Please do not open a public issue for a security problem, and please do not
post it in a discussion or pull request.

Report it privately through GitHub's
[security advisory form](https://github.com/rowenapinto001/SiteGlow-AI/security/advisories/new),
which is visible only to the maintainers.

Include what you found, how to reproduce it, and what an attacker could do with
it. A proof of concept helps, even a rough one.

You can expect an acknowledgement within a week. If the report is valid, we
will agree a disclosure timeline with you before anything is made public.

## Scope

SiteGlow AI runs entirely in the browser. Things worth reporting include anything
that lets a web page reach the extension's privileged context or its stored
data, anything that widens the permissions the extension actually uses, and
anything that sends user data somewhere it should not go.
